robot filter --select "self ancestors" only keeps the class hierarchy 
    (the entities themselves + their ancestor superclasses). 
    It does not keep annotation axioms — rdfs:label, oboInOwl:hasExactSynonym, hasDbXref, etc. 
    — unless you explicitly add annotations to the --select list.

1. Validate the Turtle first

Don't load unvalidated output straight into a running store — a malformed file can leave the graph in a bad state mid-load.

bash
riot --validate ncit_subset_annotations.ttl
riot --validate mondo_subset_annotations.ttl
riot --validate uberon_subset_annotations.ttl
riot --validate cl_subset_annotations.ttl
